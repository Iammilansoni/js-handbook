# 📘 JS Handbook

The **JS Handbook** is a comprehensive, interactive guide designed to master the core, intermediate, and advanced concepts of JavaScript. It acts as your ultimate resource for everything from `var`/`let`/`const` to Closures, Prototypes, and Higher-Order Functions.

> Elevate your JavaScript knowledge with visual mental models, practical examples, and FAANG-level interview questions.

## ✨ Features

- **Rich Visualizations**: Clear mental models and architecture diagrams for deep understanding.
- **Interactive Snippets**: Syntax-highlighted code blocks with easy-to-read themes.
- **Interview Questions**: Curated Q&A categorized by difficulty (Beginner to FAANG).
- **Common Mistakes**: Learn what *not* to do with side-by-side wrong and right examples.
- **Quick Cheatsheets**: Bite-sized summaries for quick reference.

## 🛠 Tech Stack

- **React 19**
- **Vite**
- **Vanilla CSS** (Custom Design System with Glassmorphism)
